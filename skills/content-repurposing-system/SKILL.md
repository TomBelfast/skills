# Content Repurposing System

## Overview

Turn one strong content asset into a controlled distribution package. Repurposing exists to compound reach, learn which pain converts, and bring people into Skool, email, or a paid offer.

## Repurposing Map

| Source Asset | Derivatives |
| --- | --- |
| YouTube video | Shorts, LinkedIn post, X thread, Skool discussion, newsletter, lead magnet snippet |
| Podcast | YouTube clip, article, newsletter, quote cards, Skool prompt |
| Research audit | YouTube script, LinkedIn carousel, email sequence, sales-call asset |
| Case study | Demo video, landing section, objection-handling post, proof email |

## Workflow

1. Identify the one core promise and buyer pain in the source asset.
2. Extract 3-5 atomic ideas.
3. Match each idea to platform-native format and CTA.
4. Preserve human voice; do not flatten everything into generic AI copy.
5. Add tracking: source asset, platform, CTA, target metric.
6. Schedule only after review.

## Output

| Asset | Platform | Angle | Format | Draft/Brief | CTA | Metric |

End with:

- 7-day publishing schedule
- Skool discussion prompt
- email/newsletter version
- reusable content database tags
- review checklist before scheduling

## Common Mistakes

- Posting the same wording everywhere.
- Creating content without a CTA.
- Repurposing weak source material.
- Ignoring platform-native format.
- Automating scheduling before content quality is checked.
