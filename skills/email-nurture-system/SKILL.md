# Email Nurture System

## Overview

Use email as the owned trust and sales layer between YouTube/Skool attention and paid business applications. Email should segment intent, educate, and move qualified leads toward a call, demo, audit, or purchase.

## Source Signals

Inspired by:

- `kostja94/marketing-skills`: `email-marketing`, newsletter strategy, deliverability, content mix

## Core Sequences

| Sequence | Goal |
| --- | --- |
| Welcome | Orient new subscriber and segment intent |
| Proof | Show case studies, demos, and credible outcomes |
| Education | Teach the problem and build buying criteria |
| Offer | Invite to audit, Skool, workshop, demo, or implementation |
| Reactivation | Recover inactive leads with a sharper pain/offer |

## Workflow

1. Define source: YouTube, Skool, lead magnet, audit, webinar, referral.
2. Segment by pain, buyer type, readiness, and content consumed.
3. Choose one primary conversion goal.
4. Write the sequence with one CTA per email.
5. Add deliverability basics: subdomain, SPF, DKIM, DMARC, unsubscribe, complaint control.
6. Track opens only as weak signal; prioritize clicks, replies, booked calls, and purchases.

## Common Mistakes

- Sending newsletters with no segmentation.
- Using multiple CTAs in one email.
- Treating open rate as the main KPI.
- Ignoring domain authentication.
- Letting Skool members and cold leads receive the same sequence.
